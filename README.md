# 카드 리포트 (여자친구용)

**결제하기 전에** 어떤 카드가 제일 이득인지 계산해주는 웹앱.
개인용 앱과 완전히 별도의 저장소 키를 쓰므로 같은 기기에 둘 다 설치해도 데이터가 섞이지 않음.

## 핵심 기능

1. **결제 전 추천** — 카테고리 + 금액 + 일시불/할부를 넣으면 보유 카드 전부를 계산해서 1위 카드와 예상 혜택액, 2·3위와의 차액까지 표시
2. **카드 관리** — 카드 추가/삭제/편집 (연회비, 전월실적, 카테고리별 요율, 건당·월 한도)
3. **실적 충족 토글** — 카드 혜택은 *전월* 실적 기준이라 자동 판정 불가. 카드 탭에서 직접 켜고 끄면 계산에 반영됨
4. **선택적 기록** — 추천 후 "결제함"을 누르면 저장, 월 한도 계산에 활용

## 등록된 카드 (4)

| 카드 | 연회비 | 전월실적 | 특징 |
|---|---|---|---|
| 네이버 현대카드 | 10,000원 | 30만원 | 네이버쇼핑 최대 9%대, 그 외 1% |
| 하나 제이드 클래식 | 120,000원 | 50만원 | 기본 1% 무실적 + 실적 충족 시 여행 1.5%·쇼핑 1.2%, 바우처/라운지 |
| 롯데 디지로카 라스베가스 | 20,000원 | 없음 | 전 가맹점 0.5~2%, 큰 금액 결제에 강함 |
| 하나 네이버페이 체크카드 | 0원 | 25만원 | 전 영역 1.2%, 월 한도 1만원 |

## 카드별 판단 시 주의사항

- **네이버 현대카드**: 단종되어 재발급 불가. 효율이 낮게 나와도 해지는 신중히
- **하나 네이버페이 체크카드**: 신규발급 중지 상태지만 연회비 0원이라 유지 부담 없음. 하나은행 계좌 연결 시 1.2%, 타행이면 0.6%로 반토막
- **하나 제이드 클래식**: 연회비 12만원. 2년차부터 직전 1년 600만원(월 50만원) 이상 써야 바우처가 나옴 — 이 조건을 못 채우면 사실상 연회비만 내는 카드가 됨. 유지 여부의 핵심 기준

## GitHub Pages 배포

```bash
git init && git add . && git commit -m "init"
git branch -M main
git remote add origin <레포 URL>
git push -u origin main
```
저장소 → Settings → Pages → Branch `main` / `/(root)` → Save

## iPhone 설치

배포된 URL을 Safari로 열기 → 공유 → "홈 화면에 추가"

## 혜택 정보 갱신

앱 내 **카드 탭 → 카드 선택 → 편집**에서 직접 수정 가능.

## 데이터

브라우저 `localStorage` 저장 (서버 전송 없음). 백업은 설정 탭 Export/Import.
